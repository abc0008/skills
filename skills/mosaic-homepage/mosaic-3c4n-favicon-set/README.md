# mosaic 3C.4N favicon set

A favicon-scale uppercase **M** constructed from physical tesserae. It carries
the 3C.4N material system forward: cool mineral field tiles, deep-navy
lettering, and a restrained Pinnacle-blue center inlay.

## Recommended installation

```html
<link rel="icon" href="/favicon.svg" type="image/svg+xml">
<link rel="icon" href="/favicon.ico" sizes="any">
<link rel="apple-touch-icon" href="/apple-touch-icon.png">
<link rel="manifest" href="/site.webmanifest">
```

`favicon.svg` adapts to the operating system color scheme. Explicit light and
dark SVGs are included for surfaces that need a fixed treatment.

## Files

- `favicon.svg` — adaptive light/dark SVG
- `favicon-light.svg` and `favicon-dark.svg` — fixed-theme SVGs
- `favicon.ico` — 16, 32, and 48 pixel Windows/browser icon
- `favicon-16x16.png`, `favicon-32x32.png`, `favicon-48x48.png`
- `favicon-dark-16x16.png`, `favicon-dark-32x32.png`, `favicon-dark-48x48.png`
- `apple-touch-icon.png` — 180×180
- `android-chrome-192x192.png`
- `android-chrome-512x512.png`
- `site.webmanifest`
- `favicon-test-sheet.html` — visual QA sheet

## Color specification

- Deep navy: `#14385C`
- Pinnacle blue: `#0074C4`
- Light field: `#D4D4D1`, `#C8CDD0`, `#BFC6CC`, `#D0D2D3`, `#C3C7C3`
- Dark field: `#173047`, `#1C3850`, `#244259`, `#142A3E`, `#29465D`
