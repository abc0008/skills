# Variance Analysis & Trending Reports

Create FP&A-style variance explanations, trending analyses, and management reports that explain financial performance, anomalies, and key business drivers.

## Report Types & Use Cases

| Report Type | Audience | Frequency | Focus |
|-------------|----------|-----------|-------|
| Executive Flash | C-Suite | Weekly/Monthly | High-level KPIs, critical variances |
| Business Unit P&L | BU Leadership | Monthly | Detailed variance by line item |
| Budget vs. Actual | Finance/Ops | Monthly | Plan adherence, forecast accuracy |
| Rolling Forecast | FP&A/Leadership | Monthly | Forecast revisions, trend shifts |
| Trend Analysis | Strategy/Board | Quarterly | Multi-period patterns, inflection points |

## Variance Analysis Framework

### The 4-Part Variance Explanation
```
VARIANCE EXPLANATION STRUCTURE:

1. WHAT: State the variance clearly
   "[Line item] was [$X] or [X%] [above/below] [comparison basis]"

2. WHY: Root cause explanation
   "This was primarily driven by [1-3 key drivers]"

3. SO WHAT: Business impact/implications
   "This [does/does not] impact [margin/cash/forecast] because..."

4. NOW WHAT: Actions or outlook
   "Management is [action] / We expect [outlook for next period]"
```

### Variance Materiality Thresholds
```
STANDARD MATERIALITY MATRIX:

                        Dollar Threshold    Percentage Threshold
Revenue line items:     >$100K             >5%
Gross margin:           >$50K              >200 bps
Operating expenses:     >$25K              >10%
Net income:             >$50K              >10%
Balance sheet:          >$250K             >15%
Cash flow:              >$100K             >20%

RULE: Explain if EITHER threshold is breached
      Prioritize items breaching BOTH thresholds
```

## Writing Style Guide

### Variance Commentary Principles
```
DO:
✓ Lead with the number: "$50K unfavorable" not "unfavorable by $50K"
✓ Be specific: "Customer X delayed order" not "timing issues"
✓ Quantify root causes: "3 open headcount = $45K savings"
✓ State actions: "Price increase effective March 1"
✓ Distinguish one-time vs. recurring
✓ Note if in forecast or incremental risk

DON'T:
✗ Use vague language: "various factors", "multiple drivers"
✗ Hide bad news: Lead with material unfavorable items
✗ Explain immaterial variances in detail
✗ Use jargon without definition
✗ Provide commentary without action/outlook
✗ Blame without accountability or solution
```

### Tone & Structure
```
EXECUTIVE AUDIENCE:
• Pyramid structure: Conclusion first, then support
• 3-5 bullet max per section
• Numbers in tables, insights in narrative
• Red/yellow/green status indicators
• Decision-oriented: "We need X" not just "X happened"

OPERATIONAL AUDIENCE:
• More detail acceptable
• Show calculations and decomposition
• Include trend data
• Provide drill-down capability
• Process improvement orientation
```

## Application Embedding (Regional Forecasting Module)

These sections govern the skill when embedded as the AI variance agent in the
BankAnalysis review console (`/api/regional-forecast/insights/variance-review`,
Haiku model, Pydantic-validated output).

### Per-unit variance read (Trends tab, RV_02)

Input: one row per business unit with gap percentages of 2026 annualized
actuals vs the prior-cycle plan (loans, deposits, II, IE, NII, fees, expense,
net income), the FTP decomposition (lending margin, deposit franchise at
SOFR + 0.80%), and the inputter's submission comment. For each unit, write one
WHAT+WHY note (≤200 chars) that:

- leads with the number;
- flags incoherence — balances up but NII down (margin compression / beta),
  lending margin and deposit franchise diverging, fee moves contradicting
  their balance drivers;
- reconciles with the inputter comment (confirm or challenge it);
- assigns a flag: `anomaly` (incoherent or >15% unexplained), `watch`
  (material but explainable), `normal`.

Also return one `overall` note naming the systematic cross-unit pattern —
a column lighting up across rows is an assumption shift, not a local story.

### Consolidated executive flash (Consolidation tab, RV_03)

Pyramid structure, conclusion first. `headline` is one assertion sentence with
the company-level number (a takeaway, never a label). `keyPoints` are 3–5
specific drivers with division/unit and number. `anomalies` are incoherent
patterns worth FP&A attention. `outlook` states the FY2027 budget implication.
`decisionsNeeded` are up to three decision-oriented asks. Materiality rules and
the writing style guide above apply verbatim; never narrate immaterial noise.
