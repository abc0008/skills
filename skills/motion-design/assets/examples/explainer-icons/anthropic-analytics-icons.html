How Anthropic enables self-service data analytics with Claude

Eight animated explainer icons, drawn with the subject's own objects. Headlines and figures are taken from the article.

Failure mode 1

One word, several possible entities

Concept-entity ambiguity: a term like "active" maps to more than one thing in the data model.

Failure mode 2

The model moves on; the documentation stays behind

Data staleness: definitions and schemas drift away from what was written down.

Failure mode 3

The right table exists. The agent walks past it.

Retrieval failure: the answer was present about 80% of the time, so access was not the bottleneck.

The stack

Three layers, each built to stop a different failure

Data foundations catch ambiguity, maintenance and validation catch staleness, skills catch retrieval failure.

Sources of truth

Check the semantic layer first

Sources are ordered by trust. Compiled, human-owned metric definitions come before lineage, past queries and business context.

Skills

A knowledge skill routes the question to the right reference

Without skills, accuracy stayed at or below 21%. With them it exceeds 95% in aggregate.

Validation

A second agent challenges the answer before it ships

Adversarial review added about 6% accuracy, at 32% more tokens and 72% higher latency.

Feedback loop

Every correction becomes a fix in the docs

A scheduled agent scans channels for corrections and opens one-line documentation fixes for domain owners.
