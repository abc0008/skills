# Sources & further reading

The guidance in this skill is distilled from the following. They're worth reading if
you want to extend the skill or push a particular diagram further.

## Infographic design

- **Designing Effective Infographics — Nielsen Norman Group**
  https://www.nngroup.com/articles/designing-effective-infographics/
  The core definition used here: an infographic = data/structure visualization *plus*
  context (illustration, captions, explanatory text) that reinforce each other. Source
  of the data–ink ratio, informational honesty, minimal palette, and "copy is not an
  afterthought" principles in `design-principles.md`.

- **How to Design an Infographic — Marq**
  https://www.marq.com/blog/how-to-design-an-infographic/
  Practical structure: pick a clear narrative, match the layout to the content,
  explanatory text as a first-class element.

- **How to Create Infographics — Canva**
  https://www.canva.com/learn/create-infographics/
  Audience-first framing, ≤3-colour discipline, readable type, generous whitespace.

- **46 Infographic Examples — Figma**
  https://www.figma.com/resource-library/infographic-examples/
  The three infographic types (statistical, informational, process) and a wide gallery
  that informed the catalog's form choices.

## Flowcharts & process diagrams

- **17 Types of Flowcharts — Figma**
  https://www.figma.com/resource-library/types-of-flow-charts/
  The flowchart taxonomy in `flowcharts.md` (process, workflow, data-flow, swimlane,
  decision tree, event storming, logic model, …), the five characteristics, and the
  "general" flowchart rules — applied as guidance, not orthodoxy.

- **Flowchart Symbols — Figma**
  https://www.figma.com/resource-library/flowchart-symbols/
  The standard symbol set (terminator, process, decision, I/O) — used sparingly, only
  at genuine decisions.

## Cognition (why the visuals work)

- **Mental Models — Nielsen Norman Group**
  https://www.nngroup.com/articles/mental-models/
  Why anchoring an abstract concept to a familiar mental model (a pipeline, gates, a
  funnel) makes it land — the basis of the "anchor to a mental model" principle.

- **Cognitive Maps, Mind Maps, and Concept Maps — Nielsen Norman Group**
  https://www.nngroup.com/articles/cognitive-mind-concept/
  The distinction between cognitive / mind / concept maps that informs when to use a
  concept map vs. a mind map vs. a free-form relationship diagram.
