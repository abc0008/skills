# Personal Skills

This repository contains Codex skill packages.

## Skills

- `dash-financial-apps`: Plotly Dash financial dashboards, charts, tables, and Databricks-backed apps.
- `databricks-bank-statement-auditor`: Databricks Genie-oriented internal bank financial statement footing, cross-table tie-out, organization rollup, FTP, and ledger-supported audit workflow for parsed PDF/Excel packages.
- `databricks-pdf-genie-report`: Databricks PDF ingestion, document intelligence, Genie/Agent Bricks, and governed report generation.
- `databricks-bank-financial-analysis`: Monthly internal bank financial analysis using PDF financials and IBM Planning Analytics Finance ERP Genie.

## Layout

Each skill lives under `skills/<skill-name>/` and includes a `SKILL.md` entrypoint.
